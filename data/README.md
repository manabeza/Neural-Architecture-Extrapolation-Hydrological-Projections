Data Description
This directory contains the climate input datasets required for the hybrid SWAT–deep learning experiments.
Publicly Provided Datasets

-SSP245.xlsx: Future climate and hydrological input data associated with the SSP2-4.5 scenario.
- SSP585.xlsx: Future climate and hydrological input data associated with the SSP5-8.5 scenario.
-Station_Descriptor.xlsx: Description of the station sub-basin characteristics
These datasets are provided with this repository to support research reproducibility.

Historical Data (Not Included):This data is required to excute the code

The historical hydroclimatic data were obtained from the Ministry of Water Resources and Energy of Ethiopia. 
Researchers interested in obtaining these data should submit a formal request to the Ministry, subject to its approval and applicable data-sharing requirements.

Reproduction Requirements

Before running the complete notebook, place the two separately obtained files in this directory alongside the publicly provided SSP245 and SSP585 datasets.
